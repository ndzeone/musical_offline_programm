# Музыка в офлайн

Плеер своей музыки с текстами песен, темами (Майнкрафт, Дора, Китти, Неон, Минимал) и живыми фонами.
Есть версии для **macOS**, **Android** и **Windows**.

## Скачать

Готовые установщики лежат в разделе **[Releases](../../releases/latest)**:

| Система | Файл |
|---|---|
| Android 8.0+ | `Muzyka-v2.3.0-Android.apk` |
| macOS 14+ (Apple silicon и Intel) | `Muzyka-v2.3.0-macOS.dmg` |
| Windows 10/11, 64 бит | `Muzyka-v2.3.0-Windows-Setup.exe` |

### Установка

**Android.** Скачай `.apk` на телефон и открой его. Android попросит разрешить установку из этого источника (браузера или «Файлов») — разреши и нажми «Установить». Обновления ставятся поверх, музыка и плейлисты сохраняются.

**macOS.** Открой `.dmg` и перетащи «Музыка в офлайн» в «Программы». Программа не из App Store, поэтому при первом запуске macOS переспросит:
- macOS 15 и новее: «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть»;
- macOS 14: правый щелчок по программе → «Открыть» → «Открыть».

**Windows.** Запусти `Setup.exe`. Если появится синее окно SmartScreen: «Подробнее» → «Выполнить в любом случае». Ярлык появится на рабочем столе и в «Пуске».

## Что умеет

- Своя музыка: на Mac — файлы и папки, на Android — вся музыка телефона, на Windows — файлы и папки.
- Текст песни под музыку с подсветкой по буквам или строкам (lrclib, NetEase). Если текста нигде нет, можно найти другой вариант или вставить свой.
- Плейлисты и «Любимые»: треки из файлов и с площадок в одном списке, с обложками и значком площадки.
- **Mac:** аккаунты Spotify, SoundCloud, Яндекс Музыки и VK Музыки прямо в программе, с текстом песен.
- **Android:** музыка играет в фоне и с выключенным экраном, управление из уведомления и кнопками наушников. С доступом к уведомлениям программа показывает текст и обложку того, что играет в Spotify, Яндекс Музыке, VK и SoundCloud.
- **Windows:** медиаклавиши клавиатуры и системная панель управления музыкой.
- Сохранение: плейлисты, очередь и место в треке сохраняются сразу. После перезапуска можно продолжить с той же секунды. Файл пишется целиком (не может остаться «наполовину записанным»), рядом хранится запасная копия.
- Режимы «Экономия», «Баланс», «Красота» — чтобы ни компьютер, ни телефон не грелись.
- Копия библиотеки переносится между всеми версиями (Настройки → Библиотека).

## Как устроено

```
MusicCraft/   версия для Mac (Swift, SwiftUI) — build.sh собирает .app, make_dmg.sh — установщик .dmg
web/          общий интерфейс Android и Windows (HTML, CSS, JavaScript)
android/      Android-приложение (Java): плеер в фоне, уведомление, музыка телефона, мост к интерфейсу
windows/      Windows-приложение (Electron): окно, файлы, воспроизведение
ci/           проверки на эмуляторе Android и в Windows
.github/      автоматическая сборка всех трёх установщиков
```

Установщики собирает GitHub Actions. Каждая сборка сама себя проверяет:
- Android — на эмуляторе: поиск музыки, воспроизведение, переключение, игра с выключенным экраном, сохранение после перезапуска;
- Windows — воспроизведение, перемотка, сохранение и тихая установка;
- Mac — сборка для Apple silicon и Intel и проверка образа `.dmg`.

Выпуск создаётся по тегу `v*`.

Сборка на своём Mac: `cd MusicCraft && ./build.sh` (нужны Command Line Tools), установщик — `./make_dmg.sh`.
