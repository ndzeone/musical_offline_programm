# Сервер профилей «Музыка в офлайн»

Профиль нужен, чтобы на всех устройствах было видно, какие музыкальные сервисы уже подключены.
Сервер хранит только:

- почту и имя;
- пароль от профиля в виде хэша (`password_hash`, сам пароль не хранится);
- входы с устройств (в базе — только SHA-256 от ключа входа);
- по каждому сервису и устройству — отметку «есть активация» или «нет активации».

Пароли и вход в Spotify, Яндекс Музыку, VK и SoundCloud на сервер не отправляются никогда.

## Что нужно

- хостинг с PHP 7.4 или новее (8.x лучше) и расширением `pdo_mysql`;
- база MySQL 5.7+ или MariaDB 10.3+;
- сайт по **https** (программа не отправляет пароль на адрес без https).

## Установка

1. В панели хостинга создай базу данных и пользователя. Запиши имя базы, пользователя и пароль.
2. Открой phpMyAdmin (или другой инструмент базы) и выполни файл `schema.sql` — появятся 4 таблицы с приставкой `mo_`.
3. Скопируй `config.example.php` в `config.php` и впиши данные базы:
   ```php
   'dsn'  => 'mysql:host=localhost;dbname=ИМЯ_БАЗЫ;charset=utf8mb4',
   'user' => 'ПОЛЬЗОВАТЕЛЬ',
   'pass' => 'ПАРОЛЬ',
   ```
4. Загрузи на сайт папку целиком, например в `https://твой-сайт.ru/muzyka/`:
   `api.php`, `config.php`, `.htaccess`.
   Файлы `schema.sql`, `README.md` и `config.example.php` загружать не обязательно.
5. Проверь: открой `https://твой-сайт.ru/muzyka/api.php?action=ping` — должно показать `{"ok":true,"version":1,…}`.
6. Впиши адрес в файл `server.json` в корне репозитория и отправь его на GitHub:
   ```json
   { "api": "https://твой-сайт.ru/muzyka/api.php" }
   ```
   Программы (Mac, Windows, Android) сами прочитают этот адрес — выпускать новую версию не нужно.
   Для проверки адрес можно вписать и вручную: в программе «Настройки → Профиль» внизу.

## Если что-то не работает

- `Нет связи с базой данных` — неверные данные в `config.php`.
- `Нужно войти в профиль` сразу после входа — хостинг срезает заголовок `Authorization`.
  Для Apache это чинит `.htaccess` из этой папки; программа также дублирует ключ в заголовке `X-Auth-Token`.
- `Слишком много попыток` — сработала защита от подбора пароля, подожди 15–60 минут.

## Запросы

Все ответы — JSON `{ "ok": true, … }` или `{ "ok": false, "error": "текст" }`.

| Действие | Метод | Тело | Ответ |
|---|---|---|---|
| `ping` | GET | — | `version` |
| `register` | POST | `email, name, password, device, agree` | `token, user, services` |
| `login` | POST | `email, password, device` | `token, user, services` |
| `me` | GET | — | `user, services` |
| `services` | POST | `device, services: {spotify: true, …}` | `services` |
| `logout` | POST | — | — |
| `delete` | POST | `password` | `deleted` |

`services` в ответе: `{ "spotify": { "active": true, "devices": ["Mac", "Android"], "updated": "…" }, … }`.
Ключ входа передаётся заголовком `Authorization: Bearer <ключ>`.
